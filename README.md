<h3>🚀 Featured Project — IncidentIQ</h3>

### [IncidentIQ](https://github.com/Sushantmulmuley/IncidentIQ) — AI-Powered DevOps Incident Intelligence Platform

> The only free DevOps tool combining AI incident analysis, dual-audience RCA, auto postmortem PDF, cloud cost optimization, and a DevOps AI chatbot — all in one platform. Built entirely solo.

**What makes it unique vs AWS DevOps Agent and Datadog:**

| Feature | IncidentIQ | AWS DevOps Agent | Datadog |
|---|---|---|---|
| Works with any stack | ✅ | ❌ AWS only | ✅ |
| Two-audience RCA | ✅ | ❌ | ❌ |
| Auto postmortem PDF | ✅ | ❌ | ❌ |
| Cloud cost optimizer | ✅ | ❌ | ❌ |
| DevOps AI chatbot | ✅ | ❌ | ❌ |
| Free to run | ✅ | ❌ | ❌ |

**Core capabilities:**
- 🔴 Ingests logs from AWS CloudWatch, webhooks, Slack, PagerDuty, or raw paste
- 🧠 AI root cause analysis using Groq LLaMA 3.3-70B in under 60 seconds
- 👥 Dual-audience RCA — technical breakdown for engineers + plain English for founders in one API call
- 🧠 Incident memory — cross-references every new incident against history, surfaces last known fix automatically
- 📄 Auto postmortem PDF — executive summary, timeline, action items with owners, lessons learned
- 💰 Cloud cost intelligence — reads any invoice PDF, identifies average 27% savings with specific recommendations
- 💸 Universal incident cost calculator — revenue loss, engineering time, SLA penalties, churn risk across any business type
- 💬 DevOps AI chatbot — answers infrastructure questions AND general DevOps queries with conversation memory
- 📊 Tabbed dashboard — Overview, Analyze, Cost, Incidents, Chat

**Stack:** Python • FastAPI • Groq LLaMA 3.3-70B • SQLAlchemy • SQLite • boto3 • AWS CloudWatch • Slack Block Kit • ReportLab • PyPDF2 • Twilio
